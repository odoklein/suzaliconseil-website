## 🛠️ Instructions pour le déploiement manuel

Certaines étapes ne peuvent pas être automatisées par une IA (Vérification par email, SMS, téléchargement de documents légaux Kbis).

1. **Préparation :** Téléchargez le logo `public/assets/greenlogo.svg` (ou PNG si requis).
2. **Action :** Pour chaque lien dans le tableau de suivi du fichier `FRENCH_PLATFORMS_BACKLINK_STRATEGY.md` :
   - Créez un compte avec l'adresse `contact@suzaliconseil.com`.
   - Utilisez la description correspondante ci-dessus.
   - Remplissez les informations de contact et le lien `https://www.suzaliconseil.com`.
3. **Validation :** Confirmez les emails de validation reçus.
4. **Mise à jour :** Reportez l'URL du profil créé dans le tableau de suivi pour le monitoring futur.
