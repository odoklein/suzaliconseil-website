## 🔍 Vérification de l'Indexation

### Checklist Google Search Console

**Configuration initiale** :

- [ ] Ajouter toutes les URLs de profils dans un fichier de suivi
- [ ] Créer un segment personnalisé "Backlinks Plateformes FR"
- [ ] Configurer des alertes pour nouveaux backlinks

**Vérification mensuelle** :

1. **Semaine 1 après création** :
   - [ ] Vérifier l'indexation via `site:nomdelaplateforme.com "votre entreprise"`
   - [ ] Soumettre les URLs via Google Search Console (Inspection d'URL)

2. **Semaine 2-4** :
   - [ ] Contrôler l'apparition dans les rapports de liens
   - [ ] Vérifier le statut dofollow avec des outils (Ahrefs, SEMrush)

3. **Mensuel** :
   - [ ] Exporter le rapport de liens de GSC
   - [ ] Comparer avec le tableau de suivi
   - [ ] Identifier les liens perdus ou non indexés
   - [ ] Mettre à jour les profils si nécessaire

### Outils de Vérification

**Gratuits** :

- Google Search Console (Liens > Liens externes)
- Google Search `site:` operator
- Bing Webmaster Tools

**Payants** :

- Ahrefs (Backlink Checker)
- SEMrush (Backlink Analytics)
- Moz Link Explorer
- Majestic SEO

## 🚨 Points d'Attention

### Erreurs à Éviter

1. ❌ **Duplicate content** : Ne pas copier-coller la même description partout
2. ❌ **Profils incomplets** : Remplir au minimum 80% des champs
3. ❌ **Liens nofollow** : Vérifier que les liens sont bien en dofollow
4. ❌ **Informations incohérentes** : Garder NAP (Name, Address, Phone) identique
5. ❌ **Abandon** : Ne pas créer de profils fantômes non maintenus

### Bonnes Pratiques

1. ✅ **Descriptions uniques** : Rédiger un texte différent pour chaque plateforme
2. ✅ **Visuels de qualité** : Logo HD, photos professionnelles
3. ✅ **Mise à jour régulière** : Connexion mensuelle minimum
4. ✅ **Engagement** : Répondre aux avis et messages
5. ✅ **Cohérence** : Utiliser les mêmes informations partout (NAP)
